## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram.

The project focuses on Git, GitHub collaboration, version control, Markdown documentation, and API interaction.

## How to Run

Clone the repository:

```bash
git clone https://github.com/anshv9358-code/cse103-lab-LAB3.git
```

Navigate to the project:

```bash
cd cse103-lab-LAB3
```

Run the Python program:

```bash
python3 main.py
```
